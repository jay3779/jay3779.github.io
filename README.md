# Itty Bitty Blog Monorepo

Redistribution-ready workspace organized as a monorepo.

## Structure

```
packages/
  blog-platform/      # Static blog site, scripts, and deployment workflow
  vscode-extension/   # VS Code extension source
  aah-cli/            # Local CLI for programmatic blog URL generation
docs/
  DEPLOYMENT_SUMMARY.md
  EXTENSION_INSTALL.md
  FILE_INDEX.md
  IMPLEMENTATION_SUMMARY.md
  STATUS_REPORT.md
QUICK_START.md
package.json          # npm workspaces root
```

## Included Components

- Blog platform build/test scripts
- VS Code extension source and packaging scripts
- Local-only `aah-cli` package for command-line blog post generation

## Not Included (Removed as Technical Debt)

- Root-level one-off debug/test artifacts
- Legacy temporary scripts and deprecated helper files
- Package `node_modules` directories
- Prebuilt extension output (`dist/`) and VSIX binaries
- Editor task files under package `.vscode/`

## Monorepo Commands

```bash
# Install all package dependencies (workspace)
npm install

# Blog platform tests
cd packages/blog-platform
npm test

# Extension compile/package
cd ../vscode-extension
npm run compile
npm run package

# Local CLI blog post URL generation
cd ../aah-cli
node aah-cli.js post --title "My Post" --text "# My Post"
```
